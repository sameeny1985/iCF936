Graphical Hash (SHA-256 → FI9)

Conventional hash bytes are mapped into FI9 symbols (paper §7). This is a representation layer only.

Native FI Hash (Section 7.1 – Research Prototype)

Operates entirely inside the 512-state spatial symbol space. Uses nonlinear substitution on 9-bit FI states + spatial diffusion that mixes neighbouring symbols (inspired by the 3×3 cell geometry). Not cryptographically proven – intended for experimental evaluation.

Mapping Convention Used in This Implementation

The paper defines each FI9 symbol as the binary vector
S = (c₁, c₂, c₃, c₄, c₅, c₆, c₇, c₈, c₉) where each cᵢ ∈ {0,1}.

Cell numbering (row-major): 

1 2 3
4 5 6
7 8 9

The numerical state is formed by treating cell 1 as the least-significant bit (LSB) and cell 9 as the most-significant bit (MSB). Consequently:

  • State 0 → all cells empty
  • State 1 → only cell 1 occupied
  • State 2 → only cell 2 occupied
  • …
  • State 511 → all nine cells occupied

This mapping is bijective, deterministic and perfectly reversible (Properties 1–4 of the paper). Region I (0–255) is an identity mapping onto ordinary bytes; Region II (256–511) is reserved for protocol symbols.

Source code, tests and deployment instructions are available in the accompanying GitHub repository.
